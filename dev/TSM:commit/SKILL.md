---
name: "TSM:commit"
description: Commits current working-tree changes with one Conventional Commits subject. Use when the user invokes /TSM:commit or asks to commit changes.
---

Commit the current changes.

Write a Conventional Commits message: - Format: <type>(<scope>): <description> - Types: feat, fix, docs, refactor, perf, test, build, ci, chore, revert - Scope = area touched (web, auth, db, domain, infra…); omit if obvious - One short English line, imperative, lowercase after the colon - Favor clarity over grammar; no period, no body, no fluff
